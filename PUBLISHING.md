# Public portfolio handoff

1. Create a public GitHub repository named `command-centre-portfolio`.
2. Upload the extracted files, preserving the directories. Do not upload the private Command Centre ZIP.
3. Use the description from README.md and add topics such as `portfolio`, `business-dashboard`, `workflow`, `javascript` and `typescript`.
4. Publish the `docs` folder through GitHub Pages. The demo uses relative asset paths, so it works under a repository subpath.
5. Once GitHub supplies the live Pages URL, add that exact URL to the repository's About website field and the top of README.md.
6. Pin the repository to Davinia's GitHub profile.

Only this public package has been reviewed for the showcase. Future changes must keep real credentials, campaign data and personal photographs out of the repository. Keep the synthetic-data label visible.

For reviewers who do not want to install anything, START-HERE.html is a self-contained alternative to the hosted demo.
